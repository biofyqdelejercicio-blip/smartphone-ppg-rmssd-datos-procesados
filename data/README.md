# Source datasets

Raw third-party recordings are not redistributed. Access, licensing, and citation remain governed by the original data repositories.

| Dataset | Role in this study | Source |
|---|---|---|
| Li et al. | Model development | [Mendeley Data, version 1](https://doi.org/10.17632/pz2zzr8vhm.1) |
| BIDMC PPG and Respiration | Model development | [PhysioNet, version 1.0.0](https://physionet.org/content/bidmc/1.0.0/) |
| Welltory PPG | Exploratory development only | [GitHub repository](https://github.com/Welltory/welltory-ppg-dataset) |
| WF-PPG | Exploratory development only | [Figshare dataset](https://doi.org/10.6084/m9.figshare.27011998) |
| PTT-PPG | Primary external validation | [PhysioNet, version 1.1.0](https://doi.org/10.13026/jpan-6n92) |
| Vollmer RR-interval/PPG data | Secondary external replication | [PhysioNet](https://doi.org/10.13026/chd5-t946) |
| UTSA multimodal dataset | Development subset and out-of-domain office stress test | [Official repository](https://github.com/utsanpb2-234/UTSA-PPG), [dataset article](https://doi.org/10.1109/ICHI64645.2025.00042) |

The evaluation scripts validate the expected directory structure after each dataset has been obtained from its original source. They neither download datasets automatically nor upload participant-level signals.
